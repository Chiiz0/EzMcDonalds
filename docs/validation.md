## 复现

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e . build
.venv/bin/python -m unittest discover -s tests
.venv/bin/ezmcd --data-dir .private/demo demo --run
.venv/bin/python -m build
```

[GitHub Actions](https://github.com/Chiiz0/EzMcDonalds/actions/workflows/ci.yml) 使用 Ubuntu/macOS、Python 3.11/3.14 检查安装、测试和构建。每次发布的具体 CI 结果以对应提交为准。

公开文件及发行包会检查文件清单、已知本机会话值和本地路径，排除私有账号、采样、订单资料及官方安装包。CI 不包含真实凭据，不执行真实支付。
