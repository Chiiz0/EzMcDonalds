# 从本人官方 App 首次接入

`sampling-connect` 面向已注册、已在支持的 Mac 官方 App 登录的会员，让项目自行采集一条签名余额请求并接入账号。不要求先整理HAR或复制请求；手机号、验证码和登录操作仍留在官方App。它没有实现空白设备的SDK初始化，也不是直接短信登录入口。

**a37 已通过新版已有账号钱包维护实机验收；首次创建账号仍待单独验收。** 旧版成功记录不代表新版通过；项目不再修改系统代理。参见[网络修复和边界](guarded-capture.md)。

## 准备

- 使用[账号接入文档](onboarding.md)列出的官方App版本和二进制；其他版本会停止。
- 本机采样需要 Python 3.12+ 和可选依赖。核心CLI/MCP仍支持 Python 3.11。
- 先在 App 登录自己的会员，确认麦钱包正常显示。关闭其他使用麦当劳账号的窗口，避免采到另一个会话。项目保存采样中第一个签名和余额校验通过的会话，不凭输入的别名推断手机号归属。
- 使用原数据目录；已有会员请维护原账号，不要用新目录绕过购买日志。别名或同一会员已经存在时，首次接入会拒绝覆盖。

已有账号只想更新登录会话时，使用 `sampling-connect ALIAS --update --manage-app`，仍只需进入钱包。它要求同一会员并保留原策略和购买日志；详细行为及恢复命令见[会话维护](session-maintenance.md)。

```sh
.venv/bin/python -m pip install -e '.[sampling]'
.venv/bin/ezmcd sampling-cert prepare
.venv/bin/ezmcd sampling-cert install
.venv/bin/ezmcd sampling-connect personal --manage-app
```

所有命令使用同一数据目录；自定义时把 `--data-dir /absolute/path/data` 放在子命令之前。证书首次安装由本人完成macOS系统授权，仅限当前用户的 `api.mcd.cn` SSL信任；每轮仅停止本机采样，系统代理不修改，证书保留到本人撤销。[证书说明](sampling-certificate.md)。项目不会自动安装证书。

## 一次操作

1. 阅读本机终端准备提示，按回车开始；输入 `q` 可在启动采样前取消。不能通过管道自动确认。
2. `--manage-app` 核验并退出官方App，本机进程路由与阻断自检就绪后才重新打开。省略此参数时由本人按提示退出和打开App。
3. 进入麦钱包余额页即可。不要操作购物车、登录或付款；无需提交测试订单。
4. 余额请求的官方签名与成功响应校验通过后立即收尾。有限次检查App及启动器是否退出；系统状态查询另有限时。失败则停止采样并提示手动处理，不再保证阻断，不能导入。
5. 采样结束且清理核对通过后再查询一次实时余额，成功才保存新账号。最终 `[ACCOUNT_CONNECTED]` 和 JSON 中的 `account_created=true` 表示完成接入；只看到采样就绪或余额已校验不表示已接入。失败会显示 `[ACCOUNT_NOT_CONFIRMED]`。

窗口最多120秒，可用 `--seconds 30` 缩短。`--network-service` 仅指定要检查的联网服务，默认Wi-Fi；已有活动代理时停止，绝不覆盖。网络扩展可能需要首次macOS授权，未就绪会停止，不回退到系统代理。需要时可显式指定 `--binary` 和 `--mitmdump` 路径。

首次接入期间只放行限定官方GET。保护器会拒绝捕获到的登录、短信、刷新、购物车、订单和付款写入；不得通过提交订单来测试拦截。如果App需要重新登录或刷新才能显示余额，先等本轮停止采样，再在官方入口登录后重新采样；不手工补字段，不在保护窗口里反复重试。

## 接入后

```sh
.venv/bin/ezmcd account check personal
.venv/bin/ezmcd mcp-config
```

凭据只保存于本机私有文件，不经MCP或聊天传递。首次账号消费默认关闭，没有下单运行字段；Agent可以核验会话、找店、选择商品和报价。需要下单时，先按[已有运行字段导入](guarded-capture.md)取得本人证据，再由用户设置明确消费策略。首次接入本身既不授予消费权限，也不启动定时购买。

## 失败与恢复

完成采样但实时余额核验或保存失败时，命令返回非零状态，保留采样目录、`import_error` 和 `resume_command`。后者只重新核验和导入，不启动App或代理。也可手工执行：

```sh
.venv/bin/ezmcd sampling-import personal /absolute/path/data/captures/采样编号 --connect
```

同一成功目录重复导入只查询余额，不改写凭据、策略或购买记录。别名、会员、签名、清理状态或回执不符时停止；不能覆盖已有账号、恢复已撤销凭据或替换之后更新的会话。已存在的会员使用[会话维护](session-maintenance.md)，不改名重接。未取得完整余额样本时先完成清理，再按原因开始新窗口。

采样目录含私有会话字段，权限0700/0600，不要上传仓库或发到聊天。只保留必要请求头和脱敏审计，不保存余额金额正文、Cookie、订单正文或原始代理日志。

## 当前验证范围

新版隔离测试覆盖按进程范围、原生路由与监听器分别就绪、父进程消失、启动卡住、超时、App退出失败、保持系统设置及完整证据导入。**已有账号维护的新传输已实机通过；首次创建账号尚未单独验收。**

旧版系统代理路径曾在一个已有会员完成首次接入；随后一次维护影响整机联网，用户手动关闭代理恢复。该失败与此前成功记录均保留在[验证记录](validation.md)，不能把历史成功算作新版通过。没有空白设备初始化、下单运行字段续期或跨日无人值守能力。

官方客户端可能省略会员请求头。此时项目只接受成功余额响应里的会员身份，并在保存前通过实时余额 GET 再次核对；不会从旧账号补造签名请求头。
